## 本文

### 開発背景

愛車の写真をSNSに載せたいが、ナンバープレートの処理が面倒——という声に応えるため、撮影からマスクまでをスマホ1台で完結させるツールとして開発しました。従来は画像編集アプリで矩形を切る、位置を合わせる、という手作業が必要でしたが、Carkus では AI による自動検出と、ドラッグでの手動補正を組み合わせ、短時間で「それっぽく」仕上がることを目指しています。

### 主な機能

1. **カメラ撮影 / 写真選択**  
   スマホブラウザのカメラ、またはギャラリーから画像を読み込みます。

2. **AI 自動検出（β）**  
   Google Gemini API によりナンバープレートの四隅を推定。複数プレートにも対応（最大3枚）。

3. **手動編集**  
   自動検出に失敗した場合や、微調整が必要な場合は枠をドラッグして位置・サイズ・角度を調整できます。

4. **ロゴマスク**  
   標準ロゴ（Carkus）でプレート領域を覆い、JPEG として保存・共有できます。テンプレート（Fit / Centered / Badge）の切り替えに対応。

5. **PWA 対応**  
   ホーム画面に追加してアプリのように起動できます。

### β版の制限（掲載時に明記してください）

- AI 自動検出は **1日3回まで**（日本時間 0:00 リセット）。上限後も手動編集・保存は可能
- 保存画像に **「Made with Carkus」透かし** が入ります
- サーバー混雑時は自動検出が失敗することがあります
- **有料プランは未公開**（将来提供予定だが時期未定）
- 不正利用（虚偽の文脈での利用、違法行為への利用等）は禁止

### 利用シーン

- カーシェア・オーナーが X / Instagram 等に愛車写真を投稿する前処理
- イベント・ミーティングの写真共有時のプライバシー配慮
- ブログ・note 用の車両紹介画像の下書き

### 技術概要

- フロントエンド: Next.js（React）/ PWA
- ホスティング: Vercel
- 画像解析: Google Gemini API（サーバー経由。画像は処理後に永続保存しない設計）
- 対応環境: iOS Safari / Android Chrome 推奨（HTTPS 必須）

### 今後の展望

ユーザーフィードバックをもとに検出精度・UX の改善を継続します。有料プラン（独自ロゴ、透かしなし、利用回数の緩和等）は将来検討していますが、β期間中の提供時期は未定です。
