# OpenCV プレビュー 挙動・仕様

## 概要

カメラ起動中、**リアルタイムでナンバープレートらしい四角形**を OpenCV.js で検出し、その位置に黒マスク＋ロゴを重ねて表示する。  
「撮影する」を押したあとの座標取得は **Gemini API** が行う。OpenCV は **プレビュー用の追従表示だけ** に使う。

---

## 処理の流れ

1. **カメラモードに入る**  
   - `screenMode === 'camera'` になる。
   - OpenCV.js を読み込む（`/opencv.js` → unpkg → 公式 CDN の順で試行）。
   - オーバーレイ用キャンバスが動画の上に重なる（`z-[5]`）。

2. **検出用キャンバス（小さい画像）**  
   - 動画を **320px 幅**（`OPENCV_DETECT_SIZE`）に縮小したキャンバスを **画面外**（`left: -9999px`）で `document.body` に追加。
   - 理由: 一部環境で `cv.imread(canvas)` が動くには、その canvas が DOM に存在している必要があるため。

3. **定期実行（150ms ごと）**  
   - 動画の現在フレームを小さいキャンバスに `drawImage`。
   - `detectQuadFromCanvas(smallCanvas, videoWidth, videoHeight)` を呼ぶ。
   - 返ってきた四角形（ピクセル座標）を `liveQuadRef.current` に保存。

4. **オーバーレイ描画（requestAnimationFrame）**  
   - `liveQuadRef.current` を参照。
   - **四角あり** → その四角で黒マスク＋ロゴ（またはマスク画像）を描画。
   - **四角なし** → 右下に「プレビュー: 検出中」または「読み込み中...」のみ表示。

---

## OpenCV 側の検出の中身（`detectQuadFromCanvas`）

- **入力**: 320×（アスペクトに合わせた高さ）の RGBA キャンバス。
- **処理**:
  1. `cv.imread(canvas)` で Mat に変換。
  2. グレースケール → ガウシアンぼかし。
  3. **Canny エッジ**（閾値 25, 120）で輪郭抽出。
  4. **適応的閾値**（ブロック 11, C=2）でも輪郭抽出（照明むら対策）。
  5. 両方の結果から **四角形候補** を `findBestQuadFromBinary` で取得。
  6. 面積が最大の「条件を満たす四角」を 1 つ選び、**動画の解像度にスケール**して返す。

---

## 四角形として採用する条件（`findBestQuadFromBinary`）

- **輪郭の面積**: `(画面の約 0.04% ～ 85%)` の範囲（`DETECT_MIN_AREA_RATIO` で最小を制御）。
- **形状**: `approxPolyDP` で **頂点がちょうど 4 つ** の閉曲線。**複数イプシロン（5% / 8% / 12%）** で試し、四角を拾いやすくしている。
- **アスペクト比**: 外接矩形の「長辺/短辺」が **0.8 ～ 12**（横長の四角に限定）。
- **最小サイズ**: 外接矩形の幅・高さがともに 3px 以上。
- **優先**: アスペクト比が **2.2 ～ 6**（ナンバーらしい形）の候補を優先して採用。

検出ソースは **Canny（標準＋低閾値）** と **適応的閾値** の 3 本。ナンバーが写っていればプレビューに必ず出るようパラメータを調整している。

---

## 画面に「何も出ない」ときにありがちな原因

| 現象 | 想定原因 |
|------|----------|
| 動画もオーバーレイも出ない | カメラ/ストリーム未取得、または `screenMode !== 'camera'`。 |
| 動画は出るが「検出中」も四角も出ない | オーバーレイ用キャンバスの ref が取れていない、または描画ループが動いていない。 |
| 「プレビュー: 検出中」は出るが四角・マスクが出ない | OpenCV が四角を 1 つも採用していない（条件が厳しすぎる、解像度/角度/光の影響）。 |
| OpenCV の読み込みに失敗しました | `public/opencv.js` が無い、または CDN に届かずスクリプトがロードできていない。 |

---

## 定数（変更すると挙動が変わる）

- `OPENCV_DETECT_SIZE = 320` … 検出用キャンバスの幅。
- `DETECT_INTERVAL_MS = 150` … 何 ms ごとに検出するか。
- `DETECT_MIN_AREA_RATIO = 0.0008` … 採用する四角の最小面積（画面に対する比率）。
- `findBestQuadFromBinary` 内の **epsilon（0.06）** … 四角近似の粗さ（大きいほどゆるい）。
- **アスペクト比 1.0～10** … この範囲外の四角は採用されない。

検出されすぎる場合はここを厳しく、逆にナンバーがあるのに出ない場合は緩くする。
